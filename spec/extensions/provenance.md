# LLM Provenance (`ext-provenance`)

**Version: 0.1.0** (Experimental)

The core format schema is governed independently of any single producer and omits fields that track how a world was generated by an AI model.

This extension provides a dedicated namespace for generative AI authoring tools to store lineage metadata in the world manifest without polluting the core schema.

## Fields

When an authoring tool generates a world or entity, it MAY attach the following fields inside an `ext-provenance` object (e.g. in `meta.ext-provenance`):

- `prompt`: The text string typed by the user to generate the content.
- `model`: The identifier of the LLM or generative model used.
- `generation_duration_ms`: The total time taken to generate the content.
- `biome`: A procedural generation hint specifying the environmental type.
- `semantic_category`: A string tag aiding LLM reasoning and search.

## Security and Privacy

Because `prompt` often carries the exact text typed by the author, tools circulating worlds MUST warn the user or scrub the `prompt` field before publishing the package to prevent accidental disclosure of personal information.
